# Neon Cube Run

지오메트리 대시 스타일의 원터치 점프 리듬 러너입니다. HTML5 Canvas와 순수 JavaScript로 만들었고, 외부 라이브러리 없이 브라우저 하나로 돌아갑니다.

## 바로 해보기

`index.html`을 브라우저로 열면 바로 플레이할 수 있습니다. 빌드도 서버도 필요 없습니다.

## 조작

| 입력 | 동작 |
|---|---|
| 탭 / 클릭 / `Space` / `↑` / `W` | 점프 |
| 누르고 있기 | 착지하자마자 연속 점프 |
| 노란 패드 | 밟으면 높이 튕겨 오름 |

## 레벨

1. **네온 시티**: 가시, 블록, 계단, 점프 패드, 기둥 건너기
2. **레이저 괴물**: 외눈 괴물이 레이저를 쏩니다. 낮은 레이저는 점프로 넘고, 높은 레이저는 점프하지 말고 지나갑니다. 매달린 가시 공도 피해야 합니다. 괴물 디자인은 직접 그린 그림을 바탕으로 했습니다.

## 그림으로 맵 만들기

메뉴의 **그림으로 맵 만들기**를 누르고 종이에 그린 그림을 올리면(사진 찍기도 됨) 바로 맵이 만들어집니다.

| 그림 | 맵 |
|---|---|
| 검정·진한 색 선 | 블록 (테두리만 그린 모양은 속이 꽉 찬 블록) |
| 빨강, 연필 지그재그 | 가시 (블록 아래 지그재그는 매달린 가시) |
| 노랑 | 점프 패드 (하늘에 떠 있는 노랑은 무시) |
| 연한 색 | 꾸미기 (무시) |

- 사진에서 종이를 찾아 반듯하게 편 다음 읽습니다. 종이가 사진을 꽉 채우면 그대로 씁니다.
- 그림 맨 아래, 또는 그려 둔 땅선이 바닥이 됩니다. 종이 높이를 16칸으로 나누고, **길이** 옵션으로 가로를 늘립니다.
- 여러 장을 고르면 순서대로 이어 붙입니다.
- 그림을 어떻게 읽었는지 칸으로 보여 줍니다. 틀린 칸은 **블록·가시·패드·지우개**를 골라 누르거나 문질러서 고칠 수 있고, 되돌리기와 처음대로도 됩니다.
- 만들자마자, 그리고 칸을 고칠 때마다 완주할 수 있는지 자동으로 검사합니다. 막히는 곳은 그림 위에 빨간 줄로 표시합니다.
- **자동으로 고치기**는 막힌 장애물을 낮추거나 치웁니다.
- 깰 수 있는 맵만 **링크 공유**가 됩니다. 맵 데이터는 링크(`#map=...`) 안에 들어 있어서 서버가 필요 없습니다.

## 개발

```bash
npm run verify   # 모든 레벨이 클리어 가능한지 자동 검사
npm run build    # src/ → index.html 단일 파일로 합치기
npm run test     # 그림 → 맵 변환 테스트 (합성 이미지)
npm run check    # verify + test + build
npm run serve    # http://localhost:8080 로컬 서버 (선택)
```

Node.js 18 이상만 있으면 됩니다. 설치할 패키지는 없습니다.

## 폴더 구조

```
index.html              빌드 결과물 (직접 수정하지 말 것)
src/
  shell.html            <title>, CSS, 화면 마크업 (마지막 줄이 <script>)
  core.js               물리, 충돌 판정, 레벨 데이터 (DOM 없음, Node에서도 실행됨)
  ui.js                 렌더링, 입력, 사운드, 메뉴, 게임 루프
tools/
  build.js              src/ 파일들을 index.html 하나로 합침
  verify-levels.js      레벨별 완주 경로 탐색 (기본/엄격 판정)
  test-drawing.js       그림 인식, 자동 고치기, 공유 링크 테스트
```

## 레벨 만드는 법

레벨은 `src/core.js`의 `buildLevelN()` 함수에 들어 있습니다. 좌표 단위는 **타일 1칸**이고, `x`는 출발점에서의 거리, `y`는 바닥에서의 높이입니다.

```js
S(x, y)         // 가시
B(x, w, h, y)   // 블록 (폭 w, 높이 h). 위에 올라설 수 있고 옆면에 부딪히면 죽음
J(x, y)         // 점프 패드
K(x, y)         // 가시 공. y를 1.2 정도로 주면 매달린 공 (점프하면 죽음)
LOW(x)          // 낮은 레이저 (레벨 2)
HIGH(x, len)    // 높은 레이저, len칸 동안 유지 (레벨 2)
```

새 레벨은 `buildLevel3()`를 만들어 `LEVELS` 배열에 추가하고, `src/shell.html`의 레벨 버튼과 `src/ui.js`의 `basslines`, `bests` 배열에 하나씩 추가하면 됩니다. 수정한 다음에는 꼭 `npm run verify`로 클리어 가능한지 확인하세요.
