# Jumpmap · Neon Cube Run

지오메트리 대시 스타일의 원터치 점프 리듬 러너입니다. HTML5 Canvas와 순수 JavaScript로 만들었고, 외부 라이브러리 없이 브라우저 하나로 돌아갑니다.

사진 속 손그림과 ‘DOODLE ORBIT’ 시안을 바탕으로 만든 **낙서 우주기지** 레벨이 추가되었습니다. 시작하면 새 레벨이 선택되며 기존 두 레벨도 메뉴에서 플레이할 수 있습니다. 이번 버전은 제공된 그림을 직접 레벨로 구현한 것으로, 임의 사진을 자동 분석·생성하는 기능은 포함하지 않습니다.

## 바로 해보기

`index.html`을 브라우저로 열면 바로 플레이할 수 있습니다. 빌드도 서버도 필요 없습니다.

## 조작

| 입력 | 동작 |
|---|---|
| 탭 / 클릭 / `Space` / `↑` / `W` | 점프 |
| 누르고 있기 | 착지하자마자 연속 점프 |
| 노란 패드 | 밟으면 높이 튕겨 오름 |
| Esc / 일시정지 | 멈추기·이어하기 |
| R / 다시 시작 | 현재 레벨을 처음부터 다시 시작 |

## 레벨

1. **네온 시티**: 가시, 블록, 계단, 점프 패드, 기둥 건너기
2. **레이저 괴물**: 외눈 괴물이 레이저를 쏩니다. 낮은 레이저는 점프로 넘고, 높은 레이저는 점프하지 말고 지나갑니다. 매달린 가시 공도 피해야 합니다. 괴물 디자인은 직접 그린 그림을 바탕으로 했습니다.

3. **낙서 우주기지 (Doodle Orbit)**: 종이 질감의 탐험가, 문, UFO, 꽃, 원형 얼굴 괴물, 태극 코인 24개를 재해석한 약 19초 길이의 점프 맵. UFO 아래 **붉은 스캔띠**는 점프로 넘습니다. 옅은 노란 빛은 장식입니다. 후반에는 낮은 빔을 점프로 피하고 높은 빔 아래를 달립니다. 코인은 선택 수집이며, 완주 시 수집 최고 기록을 브라우저에 저장합니다.

탭을 벗어나거나 창이 비활성화되면 플레이가 일시정지됩니다. 다시 탭하거나 Esc를 누르면 계속합니다. 재시작하면 코인이 복구됩니다. 모든 그림은 Canvas로 직접 그리므로 별도 이미지 파일이나 외부 폰트가 필요하지 않습니다.

## 개발

```bash
npm run verify   # 모든 레벨이 클리어 가능한지 자동 검사
npm run build    # src/ → index.html 단일 파일로 합치기
npm test         # 24개 코인 완주·충돌·재시작·UI 상태 회귀 검사
npm run check    # verify + test + build
npm run serve    # http://localhost:8080 로컬 서버 (선택)
```

Node.js 18 이상만 있으면 됩니다. 설치할 패키지는 없습니다.

## 폴더 구조

```
index.html              빌드 결과물 (직접 수정하지 말 것)
src/
  shell.html            <title>, CSS, 화면 마크업 (마지막 줄이 <script>)
  core.js               물리, 충돌 판정, 레벨 데이터 (DOM 없음, Node에서도 실행됨)
  ui.js                 렌더링, 입력, 사운드, 메뉴, 게임 루프
tools/
  build.js              src/ 파일들을 index.html 하나로 합침
  verify-levels.js      레벨별 완주 경로 탐색 (기본/엄격 판정)
```

## 레벨 만드는 법

레벨은 `src/core.js`의 `buildLevelN()` 함수에 들어 있습니다. 좌표 단위는 **타일 1칸**이고, `x`는 출발점에서의 거리, `y`는 바닥에서의 높이입니다.

```js
S(x, y)         // 가시
B(x, w, h, y)   // 블록 (폭 w, 높이 h). 위에 올라설 수 있고 옆면에 부딪히면 죽음
J(x, y)         // 점프 패드
K(x, y)         // 가시 공. y를 1.2 정도로 주면 매달린 공 (점프하면 죽음)
LOW(x)          // 낮은 레이저 (레벨 2)
HIGH(x, len)    // 높은 레이저, len칸 동안 유지 (레벨 2)
```

새 레벨은 다음 `buildLevelN()`을 만들어 `LEVELS` 배열에 추가하고, `src/shell.html`의 레벨 버튼과 `src/ui.js`의 `basslines` 배열에 음악을 추가하면 됩니다. `bests`는 레벨 수에 맞춰 초기화됩니다. 수정한 다음에는 꼭 `npm run verify`로 클리어 가능한지 확인하세요.

## 이번 구현의 검증 범위

- 기존 두 레벨과 낙서 우주기지 모두 기본·엄격 충돌 판정에서 완주 경로를 확인했습니다.
- 60Hz와 실제 게임의 120Hz 물리 스텝에서 한 번에 코인 24개를 모두 모아 완주하는 경로를 검사합니다.
- UI 테스트는 Canvas·DOM 모형에서 메뉴 전환, 일시정지, 재시작, 완주 화면, 기록 저장을 확인합니다. 브라우저 시각 검증을 대체하지 않습니다.
- 이번 작업에서는 셸 실행 환경을 사용할 수 없어 JavaScript 실행기에서 저장소의 검증·빌드 스크립트를 실행했습니다. 파일 입출력과 Node 모듈은 메모리 어댑터로 연결했으며, 실제 브라우저 실플레이 및 온라인 배포는 확인하지 못했습니다.
